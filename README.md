# WarpNexus

Plugin de warps para PocketMine-MP 5.x. Lo hice porque los existentes o son feos visualmente o no tienen la funcionalidad que necesitaba para mi servidor.

## Características

- **Menú visual** — Inventario doble con items custom, no un chat aburrido
- **Edición completa** — Cambiá nombre, lore, slot, item y posición sin tocar archivos
- **Sistema de slots** — Organizá los warps arrastrando en el menú de edición
- **Colores** — Paleta rosa/morada en todo, nada de gris genérico
- **Delay con cancelación** — Si te movés durante el teleport, se cancela

## Comandos

| Comando | Permiso | Descripción |
|---------|---------|-------------|
| `/warp` | `warp.nexus.use` | Abre el menú de warps |
| `/setwarp nombre` | `warp.nexus.admin` | Crea un warp en tu posición |
| `/delwarp nombre&` | `warp.nexus.admin` | Elimina un warp |
| `/warp edit` | `warp.nexus.admin` | Lista de warps para editar |
| `/warp edit nombre&` | `warp.nexus.admin` | Edita un warp directamente |
| `/warp editmenu` | `warp.nexus.admin` | Mueve warps de slot visualmente |
